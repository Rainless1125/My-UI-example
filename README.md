# UI Atlas — 現代化網頁 UI 元件庫與提示詞

10 大類別 × 每類 20 款，共 **200 個**現代化網頁 UI 元件。所有元件都能在同一個網頁上即時預覽與互動，並可一鍵複製「做出相同或類似效果」的 AI 提示詞。

- 介面預設為**淺色模式**，右上角可切換深色（元件同步支援深色）
- 全站**不使用任何 emoji**，圖示一律使用 [Font Awesome 6](https://fontawesome.com/)（已驗證皆在免費字型內）
- 不需要建置，直接用瀏覽器開啟 `index.html` 即可

## 功能

- **複製提示詞**：每張卡片右下角一鍵複製；提示詞包含設計重點與共通規範（配色、字體、狀態、無障礙、禁用 emoji 等）。
- **輸出技術切換**：右上角可選擇提示詞要產生 `HTML + Tailwind`、`React + TypeScript + Tailwind`、`Vue 3 + Tailwind` 或 `HTML + 原生 CSS`。
- **檢視原始碼**：點 `</>` 開啟側邊抽屜，可看大預覽、複製 HTML 片段、複製完整單檔，或直接下載可獨立執行的 `.html`。
- **複製整類提示詞**：類別標題右側可一次複製該類 20 則提示詞。
- **搜尋**：`Ctrl / Cmd + K` 聚焦搜尋，可跨類別搜尋名稱、英文名、標籤與設計描述。
- **收藏**：點愛心收藏元件（儲存在瀏覽器 localStorage）。

## 檔案結構

```
index.html            展示頁外殼
assets/kit.js         設計 Token、Tailwind 設定與元件互動函式（UIK）
assets/app.js         類別導覽、搜尋、收藏、提示詞產生與複製
assets/app.css        外殼樣式
components/*.js       每個類別一個檔案，各含 20 個元件資料
```

### 新增元件

在對應的 `components/<類別>.js` 的 `items` 陣列中加入：

```js
{
  name: '元件中文名稱',
  en: 'English Name',
  tags: ['標籤一', '標籤二'],
  wide: false,            // true 時在寬螢幕佔兩欄
  spec: ['設計重點 1', '設計重點 2', '設計重點 3'],  // 會組成提示詞
  html: `<button class="...">...</button>`,
}
```

元件樣式使用 Tailwind utility class 與以下語意化 Token（會自動適應深淺色）：
`bg-canvas`、`bg-surface`、`bg-subtle`、`border-line`、`text-ink`、`text-ink-soft`、`text-ink-faint`、`brand-50…950`。
